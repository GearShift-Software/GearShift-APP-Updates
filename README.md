- **Proven only:** tweaks with no measured gain stay hidden unless you ask to see them.
- **Reversible:** a restore point is made first, and every change has its own undo.

- **Private:** no account and no tracking. Sharing anonymous hardware and performance data is opt-in.

## Install
1. Download **[GearShift-Setup.exe](https://github.com/GearShift-Software/GearShift-APP-Updates/releases/latest/download/GearShift-Setup.exe)** from the latest release.
2. Run it. If Windows shows "Windows protected your PC", click **More info > Run anyway**. New apps from small developers show this until they build up reputation.
3. That's it. GearShift checks for updates and offers them in the app.

**Requirements:** Windows 10 or 11, 64-bit.
