## Four rules
- **Proven only:** tweaks with no measured gain stay hidden unless you ask to see them.
- **Reversible:** a restore point is made first, and every change has its own undo.
- **Security stays on:** GearShift never turns off Defender, the firewall, Windows Update or other protections, unless you want to "wink, wink".
- **Private:** no account and no tracking. Sharing anonymous hardware and performance data is opt-in.

## Install
1. Download **GearShift-Setup.exe** from the [latest release](https://github.com/YOURNAME/gearshift/releases/latest).
2. Run it. If Windows shows "Windows protected your PC", click **More info > Run anyway**. That warning shows up for new apps from small developers.
3. GearShift updates itself when a new version is out.

**Requirements:** Windows 10 or 11, 64-bit.

## Updates
Every version is listed under [Releases](https://github.com/YOURNAME/gearshift/releases) with its changes. Installed copies check for updates and offer them in the app.

## What's in this repo
This repo hosts the downloads and the game and hardware lists the app reads (`library/`). Each list is digitally signed, and GearShift ignores any file whose signature doesn't match. The app's source code is not published here.
